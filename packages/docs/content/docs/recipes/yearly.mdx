# Yearly View

Set `monthsToDisplay` to `12` to display a full year calendar. Clicking next or previous navigates by a full year at a time.

<YearlyDemo />

---

## Code Example

```tsx
import { Calendar } from 'react-modular-datepicker';

export function YearlyExample() {
  return (
    <Calendar
      monthsToDisplay={12}
      classNames={{
        calendarsContainer: 'grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-4 mt-3 w-full',
        day: {
          day: 'aspect-square flex items-center justify-center text-xs font-medium p-0',
        },
      }}
    />
  );
}
```
