# Yearly View

Set `monthsToDisplay` to `12` to display a full year calendar. Clicking next or previous navigates by a full year at a time.

<YearlyDemo />

---

## Code Example

```tsx
import { Calendar } from 'react-modular-datepicker';

export function YearlyExample() {
  return (
    <Calendar
      monthsToDisplay={12}
      classNames={{
        calendarsContainer: 'grid grid-cols-1 md:grid-cols-3 gap-6 mt-3 max-w-5xl',
      }}
    />
  );
}
```
