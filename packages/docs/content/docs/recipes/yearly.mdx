# Multi-Month Grid

Set `monthsToDisplay` to 2, 3, 4, or 12 to display multiple months simultaneously.

<YearlyDemo />

---

## Code Example

```tsx
import { Calendar } from 'react-modular-datepicker';

export function MultiMonthExample() {
  return (
    <Calendar
      monthsToDisplay={4}
    />
  );
}
```
